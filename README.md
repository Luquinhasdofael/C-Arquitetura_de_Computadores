<h3>Contextualização</h3>
<p>Atualmente, a arquitetura de computadores é baseada um conjunto de dispositivos eletrônicos que são capazes de distinguir, com precisão, entre dois sinais de um sinal elétrico, caracterizados comumente por 0 e 1. Por isso, dados e operações, em um computador, é representado por uma linguagem de apenas 2 símbolos, isto é, linguagem binária. Cada símbolo recebe o nome de <strong>bit²</strong></p>
<h3>CPU</h3>
<p>A CPU(Central Processing Unit) é o componente responsável por executar as instruções de um programa, em linguagem de maquina. Durante a execução do programa, o processador "lê" a instrução corrente, realiza as operações especificadas na instrução e determina qual a próxima instrução a ser executada. Esse processo se repete até o processador ler uma instrução que indique o fim do programa.</p>
<h2>Registradores</h2>
<p>O processador precisa de um lugar para retirar os operandos de uma instrução e para guardar temporariamente o resultado. Para isso utiliza-se de uma estrutura chamada registradores, imaginem como uma caixinha com um nome único que guarda uma informação(dados/valores) de cada vez de forma temporária. Na computação, os operandos e resultados recebem o nome de dados ou valores: Uma sequência de bits que podem ser um caractere ou número.  </p>
